# 力量计时

离线安卓力量训练计时器，支持 Android 8.0 及以上。

- 常用动作选择、自定义动作名称；30/45/60/90 秒快捷时长和自定义秒数。
- 训练总览显示动作数、目标组数及包含休息的固定用时；次数动作不虚构预计时长。
- 内置全身、核心和下肢模板；支持命名保存、切换、覆盖确认和删除自定义方案，全部离线存储。模板仅为可编辑的计时清单。
- 环形倒计时显示当前阶段剩余比例；绿色训练、橙色休息，下方进度条显示整场训练进度。
- 开始训练按钮固定在清单底部，不随列表滚动；移除底部导航，训练记录与设置位于右上方。两者都是同样的整页子页面，点击进入和返回时使用 260 毫秒的滑动过渡，保留原页面滚动位置；快速连续切换不重复保留旧控件，系统关闭动画时立即切换。返回恢复进入前的页面，后台计时继续运行。
- 切换方案、保存方案、动作编辑、添加动作、添加休息及各类确认统一使用圆角底部面板、卡片输入框和固定操作按钮；常用动作与休息类型也使用相同风格的选择按钮。面板顶部横条与标题区支持下拉关闭，短拖动回弹，也可点横条关闭；输入框、音量滑块和列表滚动互不干扰。错误提示在输入卡片内显示，短消息及计时进度条也使用统一的圆角样式。
- 使用用户提供的两个 MP3：`cue_start.mp3` 用于开始、继续和进入训练阶段；`cue_pause_end.mp3` 用于暂停、进入休息、提前结束和完成。可调音量并分别试听，振动可独立开关，结束音完整播放。
- 设置中可分别开启训练和休息倒计时朗读，独立设置起读秒数（1–60，默认 10 秒）；进入范围后用中文真人女声逐秒读到 1。默认关闭，内置 Shtooka / Yue Tan 的真人数字录音（CC BY-SA 3.0 US），在设置中可查看来源与许可，不依赖手机语音引擎或联网。暂停、跳过和结束会停止旧读秒；延迟时只读当前秒数，不补读过去的数字。音效开关与朗读独立，二者共用音量控制。
- 每个训练动作可开启“非计时（按次数）”：单次时长改为每组次数（1–999），每组结束点击“完成这一组”，自动进入小休息，最后一组后进入大休息；休息为 0 时直接进入下一阶段。时长与次数独立保留，模式跟随方案保存、复制及恢复。训练页与通知栏均可完成，未确认不会自动记组或结束，暂停后需要继续再完成。
- 每个动作可配置组数、组间小休息、动作后大休息（0 秒表示关闭）。
- 长按卡片左侧 ≡ 拖动排序，也可在编辑面板底部上下移动、复制、删除。
- 自定义大/小休息可作为独立项目插入并拖动；自动休息跟随所属动作。
- 自动切换阶段；暂停、继续、跳过、提前结束并保存。
- 完成一段训练计时或手动完成一个次数组记 1 组；跳过不记完成组。不自动测量动作重复次数。
- 训练历史显示每个动作完成组数、有效训练时长、跳过组数；保留最近 200 次。可确认删除单条或清空当前记录；固定编号避免后台新增记录时删错。支持导出 UTF-8 CSV 表格或包含全部原始字段的 JSON，在系统文件选择器中指定保存位置；取消导出保留数据。导出使用点击时的记录快照，手机旋转或后台新增记录不会改变待导出的内容。
- 通知栏控制、后台和锁屏计时、可开关提示音和振动。
- 系统强制终止后，重新打开恢复为暂停状态，不虚增训练次数。

小休息仅在两组之间执行；最后一组后直接执行大休息。最后一个动作的大休息也会执行，不需要可设为 0。独立休息块与动作自动休息会累加。

## 安装
GitHub Actions → Build Android APK → 成功运行 → strength-timer-apk，解压安装 APK。
新版安装包版本为 1.6.0，使用原有发布证书签名后可覆盖升级此前版本并保留原有训练计划与记录。
首次运行建议允许通知，便于锁屏暂停或跳过。部分手机需在系统设置允许应用后台运行。

## 云端构建
本机无需 Android SDK、Android Studio 或模拟器。GitHub Actions 使用 JDK 17、Gradle 8.9、Android Gradle Plugin 8.7.3、Android SDK 35。
推送 main 或手动运行工作流会执行纯 Java 计时测试、Android lint、签名 release 构建，以及保留动画的 Android 15 模拟器的 14 项界面与数据测试（含记录删除与导出选择、导出字段和并发删除、设置与记录子页面返回及重建、次数模式完成与自动休息、训练/休息朗读设置持久化、各面板下拉关闭、开始按钮位置固定、顶部导航与返回、编辑面板校验、设置持久化、方案保存切换、拖动排序和后台计时），输出测试报告和界面截图。

构建兼容性依据：[Android 官方 AGP 8.7 说明](https://developer.android.com/build/releases/agp-8-7-0-release-notes)。后台服务声明遵循 [Android 官方前台服务类型说明](https://developer.android.com/about/versions/14/changes/fgs-types-required)。

签名证书通过私有仓库 Actions secrets `KEYSTORE_BASE64` 与 `SIGNING_PASSWORD` 管理，后续安装包沿用同一签名，可覆盖升级。请备份签名证书；丢失后无法直接覆盖安装已有版本。
手机数据只保存在应用本地，不联网、不收集账号信息，卸载后数据会清除。

## 项目
`MainActivity.java`：计划编辑、拖动、计时和记录界面。
`Workout.java`：独立于 Android 的时间线和计时引擎。
`TimerService.java`：后台服务、单调时钟、通知和提示。
`Store.java`：计划、训练快照和历史记录。
